# The manager (retired)

The manager, a conversation that briefed hidden worker bots and
relayed their reports, was replaced on 2026-11-09 by the one
conversation per machine with tasks and topics: see
[one-loop.md](one-loop.md). A machine that still has a manager and
workers is adopted at the first open of that version
(`rragent.migration`, one-loop.md §9); the workers' chats stay
readable behind the settings' advanced switch.
