# The manager (retired)

The manager, a conversation that briefed hidden worker bots and
relayed their reports, was replaced on 2026-11-09 by one conversation
per machine ([one-loop.md](one-loop.md)), and that on 2026-11-10 by
the bots without a manager: see [bots.md](bots.md). A machine that
still has a manager and workers opens with every one of them a bot
like the others (`rragent.migration`, bots.md §8).
